FAQ

Questions, answered

Which platforms are supported?

YouTube, Twitch, Kick, Rumble, Dailymotion and Vimeo links are detected automatically, plus any direct HLS/m3u8 stream — useful for live TV channels. Any other website URL is embedded as-is. Just paste the URL.

How many streams can I add?

Up to 24 streams in a single grid. The layout scales from a single full-screen player up to a 6×4 wall.

Can I share my grid?

Yes. The Share button copies a link that encodes your exact set of streams and the names you gave them. Anyone who opens it sees the same wall.

What are mirrors?

A mirror is a second source for the same channel — a YouTube feed and the broadcaster's own m3u8, for example. Open a tile's ⧉ button to add mirrors and switch between them without disturbing any other tile.

Does it work on mobile?

Yes — on narrow screens the grid stacks vertically so every stream stays watchable.

Why won't a Twitch stream load?

Twitch embeds only play on real hosted domains (the player checks a parent parameter). Host this file on any domain — even a free static host — and Twitch tiles will work. YouTube likewise refuses embeds opened straight from disk (Error 153), so serve the page over http(s).
